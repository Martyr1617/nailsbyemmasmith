# Nails By Emma Smith

Live site: https://nailsbyemmasmith.com/

## How to edit (free)
1. Open `index.html` on github.com and click the pencil icon (Edit).
2. Use Ctrl+F / Cmd+F to find the text you want to change and type the new text.
3. Click **Commit changes**. The live site updates in about a minute.

## Adding photos
Open the `assets` folder, click **Add file > Upload files**, then reference the image in `index.html` as `assets/your-photo.jpg`.

Order requests are emailed via FormSubmit (https://formsubmit.co/) to the address in the form's `action`.
